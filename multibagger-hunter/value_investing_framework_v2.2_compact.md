# Forensic Value/GARP Framework (v2.3 — Compact/Lossless)

Act as a forensic financial analyst + expert value/GARP investor (Buffett, Munger, Graham, Lynch, Kedia). Goal: dissect the company with extreme skepticism, actively trying to **invalidate** the thesis — while not throwing out a genuine long-runway compounder on a valuation technicality. Analyse **[COMPANY & TICKER]** at **[PRICE]**. If held, state **[shares & avg cost]** — cost is an input to sizing/tax only, **never** to the verdict (see Exit).

## Hierarchy of judgement (read first)
A multibagger is identified by the **business**, not a DCF. Keep evidence in three axes:
- **HARD GATES — only these kill the thesis alone → Avoid/Exit:** (1) **Business quality** — durable high growth, large runway, cash-backed profit, high sustainable returns on capital (§1,5,6); (2) **Governance/forensic integrity** — honest aligned mgmt, clean accounting, no tunneling, cash matches profit (§2,3).
- **LENSES — set price paid & size taken, never veto an A+ business:** Valuation (§4) at most moves **Buy→Wait/Watch**; it cannot disqualify a business that cleared both gates.
- **MANDATE FIT (§0)** — separate axis → verdict **RETIRE** (not Hold, not Avoid). Don't let mandate-mismatch masquerade as a quality judgement, or quality override a mandate mismatch.
- **TWO SLEEVES:** Core GARP (small, undiscovered, explosive-runway, conviction-sized) + optional capped **Satellite Quality-Compounder/Deep-Value** (A-grade businesses caught at a genuine discount). A name clearing both gates but failing the *core* mandate purely on **growth-ceiling/size/spent-discovery**, *and* on sale → routes to satellite **OWN** (§8), not reject. Discount mandatory; fair value = Hold/Retire. **Satellite is size-agnostic on the upside** (the home for proven mid/large-caps too big for core) and holds **two flavours:** a quality *compounder* at a discount, and a **proven business at a deep-value/re-rating discount** (~2–3x on wide MoS). Explicit, capped choice; on a pure single-mandate book it collapses to RETIRE.
- **Weight the DCFs unequally.** **Reverse DCF = primary** (expectations diagnostic: "what must be true at this price?" — falsifiable). **Forward DCF = light sanity check only** (manufactures value from unforecastable far cash flows; blind to the re-rating engine, which is a discovery/sentiment event). Every forward-DCF output is a **range, never a point.**
- **What actually breaks a thesis:** (a) overpaying at a hype/cyclical top — reverse DCF guards; (b) the story breaking (fraud, WC-trap, serial dilution, competitive erosion) — the **forensic/quality gates** guard, not the DCF.

## §0 Mandate & Applicability Screen — RUN FIRST (don't bury in §8)

### 0.1 Mandate fit
State mandate parameters, then score:

| Criterion | Requirement | This company |
|---|---|---|
| Market cap | [band, e.g. ₹300–2,500cr] | |
| Institutional discovery potential | Pre-discovery/underfollowed | FII%+DII%+shareholder count |
| SMILE "S" — distance from ~₹5–6kcr threshold | Below, with room | |
| Sell-side coverage | Sparse to none | |
| Plausible return ceiling (from §7) | Consistent with target multiple | |

**Tiered size band (market cap is a proxy; ownership is the substance — where they disagree, ownership wins):** **Core sweet spot ~₹300–2,500cr** (both engines live); **Extended/graduation-watch ~₹2,500–5,000cr** (core-eligible only if still genuinely undiscovered on ownership/coverage AND the earnings engine carries most of the return — thin re-rating headroom left; a name already fund-owned fails regardless of rupee figure); **Hard ceiling ~₹5–6kcr+** (discovery presumed spent → RETIRE/satellite unless ownership proves institutions still absent). A ₹4,000cr name 3% fund-owned & uncovered is more pre-discovery than a ₹1,500cr name 25% fund-owned. Templates — revisit as market-cap inflation/DII flows push the threshold up.
**Graduation-zone rule:** a name already *through* pre-discovery is a mandate disqualifier **independent of quality** — inst.ownership >~20%, saturated coverage, or index membership means the discovery re-rating leg no longer exists. Say so in para 1.
**Satellite routing (instead of a straight reject):** classify *why* the core mandate failed — failed on **quality/governance** (a hard gate) → **Avoid/Exit**, satellite closed; failed **only** on growth-ceiling/size/spent-discovery, **both gates clean + real per-share compounding** → **Satellite Quality-Compounder candidate (§8)**, earning **OWN only if also at a genuine discount**; at fair value → Hold (if owned)/Retire (if not). The discount is the whole difference between "worth buying into a satellite sleeve" and "nothing to do here."
**Don't run a full 8-section analysis on a name 10x+ outside the band** unless asked; if asked, carry the mandate verdict to §8 and expect **RETIRE**.

### 0.2 Sector applicability adapter (financials break the machinery)
On **banks, NBFCs, insurers, holding cos, REITs/InvITs** several tools mislead. Substitute:

| Tool | Breaks on | Substitute |
|---|---|---|
| FCF/Owners'-Earnings DCF | Banks/NBFC/insurers | **Residual-income (excess-return) model + justified P/B=(ROE−g)/(CoE−g)** + DDM check; insurers **P/EV** |
| CFO/PAT, cash-cycle, WC-days, WC-trap gate | Banks/NBFC/insurers | **Asset-quality gate:** GNPA, NNPA%networth, PCR, slippage, SMA-1/2, restructured book, CET1/CRAR |
| ROCE | Any lender | **RoA + ROE together; never ROE without the leverage multiple** |
| Screener auto FCF/CFO-OP%/WC-days/"capitalizing interest"/contingent-liab flags | Banks/NBFC/insurers | **Disregard and say so** (machine-generated on industrial assumptions) |
| Operating-leverage/RJ setup (§5) | Lenders, asset-light services | **Cost-to-income + credit-cost normalisation;** state RJ setup structurally absent |
| Depreciation/maint-capex/CWIP | Financials, asset-light | Skip w/ one-line note |
| Standard DCF terminal value | Holding cos | **SOTP + explicit justified holdco discount** |

Rule: **if substituting >3 tools, say the framework is run in adapted form and name every substitution.**
**Financials — additional MANDATORY checks:** (1) **Bank moat is the LIABILITY side** — low-cost, sticky, granular **deposit franchise** (CASA, cost-of-funds vs peers, retail-vs-bulk, trend); a high-NIM book funded by hot money has no moat. Score the deposit franchise as the §1 moat. (2) **NBFCs/HFCs have no deposit franchise** — borrow short, lend long; failure mode = **funding freeze** (IL&FS/DHFL). Test **ALM gaps, borrowing-mix concentration, short-term/CP share, rollover dependence.** Don't lump with banks. (3) **NIM-cycle normalisation (double-peak trap):** peak NIM + trough credit cost simultaneously = the "cheap" P/E is the market refusing to capitalise unsustainable earnings; normalise NIM to mid-cycle. (4) **Internal capital generation vs dilution:** self-funding growth ≈ **ROE×retention**; growth above it → equity raises coming; **a raise below book destroys per-share value** (tie to §2 dilution taxonomy). State whether growth is self-funding or dilution-dependent, and the price at which a raise is accretive. (5) **CoE discipline for justified P/B:** formula is hypersensitive and explodes as g→CoE; name CoE (~12–14% Indian financials), don't re-derive quarterly, **show a P/B sensitivity grid across CoE and g, never a point**; anchor on a range + peer ROE cross-check. (6) **Insurers:** value on **P/EV**; check **VNB margin/growth, persistency (13th/61st month)**; life (EV/VNB) vs general/health (combined ratio, P/B on float). **Reported book can be fiction — haircut it:** cross-check NNPA%networth, PCR trend, restructured/SMA book, write-offs, ARC sales; under-provisioning flatters PAT *and* book.

### 0.3 Data-integrity pre-check (all)
1. **Live price** — Screener cache is stale; cross-check a live quote (note both dates/times) before valuation.
2. **Split/bonus** — test EPS series vs `PAT/(equity capital/face value)` earliest year; if it doesn't reconcile, recompute per-share from equity capital & net worth.
3. **Consolidation discontinuities** — subsidiary acquired/deconsolidated/dropped <50% breaks YoY lines; name the quarter and cause.
4. **PAT vs EPS** — confirm `EPS×shares≈PAT`; a gap = minority interest/exceptionals/error; if consolidated won't reconcile, use standalone and say why.
5. **Feed errors** — million-as-crore, standalone/consolidated conflation, 10x errors circulate; filings beat every aggregator.
6. **BASE-YEAR integrity for EVERY CAGR (low-base trap):** inspect the base year; a distorted trough (COVID/one-off-loss/impairment/near-zero/strike/pre-turnaround) makes the CAGR a recovery artefact → **discard or recompute off a normalised base** (e.g. a "132% 5-yr PAT CAGR" off a ₹2cr COVID base → restate off FY20 → ~27%). **Do not carry a sub-normal-base CAGR into §4/5/7;** state the base year used.
7. **LIVE-EVENTS & recency search (before finalising governance/risk gates):** search last ~6mo for pending litigation/court/tribunal, SEBI/RBI action, **lease/licence/concession renewal disputes**, rating changes, promoter pledge/stake changes, auditor/board resignations, any threat to a core asset's *tenure or licence*. Date the latest item. For a **single-asset/single-licence business a live tenure/licence threat is existential (hard-gate), not peripheral** — put it in §3 top risks; it can cap conviction regardless of clean financials. If nothing, say so explicitly.

## §1 Business, moat, market dynamics *(HARD GATE — quality)*
- **Blueprint:** what it does; how operations convert to liquid cash; who pays and what triggers recurring revenue; primary segments (% mix, growth, margin), customer concentration, geography.
- **Moat:** durable advantage (switching costs, network effects, cost leadership, brand/intangibles) or commodity price-taker? Can it earn **ROIIC > cost of capital** over the next decade? **Prove widening/eroding with a multi-period metric trail** (realisation, gross/net margin, spread, share), not assertion. Where pricing is **set/auto-repriced by regulation, contract, or benchmark linkage**, say so: that is structural price-taking, not fixable by management.
- **Sector outlook & demand integrity:** 5–10yr macro; fragmenting or consolidating? Judge **demand integrity** — underperformance an operational hiccup (temporary margin compression, destocking, transitory regulation) or **structural** decline (obsolescence, permanent moat loss, changed behaviour)? State: business to avoid, or hiccup to bet on.
- **Capacity & the growth ceiling (required — the "industry is growing" fallacy):** state **current utilisation** and the **physical/structural volume ceiling** (installed capacity vs output, occupancy, licence/quota, land/footprint, deposit/funding for a lender, billable-headcount for services). **A capacity-bound business grows with its OWN capacity, not its industry, until named new capacity commissions** — industry/TAM growth is *irrelevant* as the company's rate while capacity-constrained (the commonest way achievable growth is overstated). If growth needs new capacity, **name the project, cost, commissioning date, and the lag**; treat everything before that date as price/mix only. Carry this number to §4.
- **Per-share primacy (required):** a compounder compounds **per share**. Restate history to today's share count: **BVPS & EPS** start/end + CAGR of each; **net-worth-growth multiple vs share-count-growth multiple** side by side; **segment by capital-structure regime** (don't run one long CAGR across a heavy-dilution episode — report crisis/dilution era and flat-share era separately, e.g. *"BVPS −5% FY15–26 overall, but that's all FY15–22 recap dilution; share count flat since FY22, BVPS +13.9% over those 4yrs"* — the long window is a governance warning, the recent regime is today's engine; report both). **Hard-gate call:** a decade of flat/negative per-share = business-quality failure for a compounder mandate even if the enterprise grew — state whether it's **"not a compounder"** or **"not a viable business"** (different verdicts, §8).

## §2 Management, capital allocation, anti-tunneling *(HARD GATE — governance)*
- **Minority treatment:** history of favouring self over minorities? Red flags — high promoter remuneration, excessive RPTs, renting property from promoters, opaque multi-layer subsidiaries. **Review annual-report RPT schedules directly** (screener/third-party routinely omit/misrepresent).
- **Controlling-shareholder taxonomy (don't score holding generically):** "high holding, zero pledge" is only a positive for a founder/family owner-operator.

  | Promoter type | High holding | Zero pledge | Risk to test |
  |---|---|---|---|
  | Founder/family owner-operator | Genuine skin — **positive** | Positive | Succession; RPT tunneling; key-man |
  | Sovereign/State (PSU) | **Not** alignment — policy actor; positive only as solvency backstop | **Meaningless** (can't pledge) | **Below-book recap diluting minorities**; directed lending; policy burden; ~3yr CEO terms preclude owner-operator alignment |
  | Professional/institutional/MNC parent | Neutral | Neutral | Transfer pricing; royalty extraction; minority squeeze-out |
  | PE/financial sponsor | **Negative-leaning** (exit-driven) | Neutral | Block-sale overhang; leverage loaded pre-exit |

  Where promoter is sovereign or sponsor, **the dilution record is the governance test that matters**, not the pledge column.
- **$1 retained-earnings test:** for every ₹1 retained, ≥₹1 of market value created? Show the math. **Run over TWO windows:** (a) recent 3–5yr, (b) longest window **including the worst drawdown/dilution episode** — a 5yr test off a distressed trough measures the re-rating, not retention quality; **where they disagree, the full-cycle window governs the hard gate**, recent describes today's regime. Also decompose net-worth growth: **% from fresh equity vs retained earnings** — **>~25% from new shares over a cycle = serious per-share warning.** (First distinguish a commissioning trough from structural erosion — §5.3 — don't penalise a genuine inflection on depressed trailing returns alone.)
- **Reinvestment runway vs return of capital:** classify — (i) high-return + long runway (reinvest — best); (ii) high-return + no runway + disciplined payout at sensible prices (acceptable cash cow); (iii) high-return + no runway + empire-building/idle cash (red flag); (iv) **moderate-return + long runway** — reinvesting 1–2pts above CoC is technically accretive but unexciting, say so rather than scoring it a compounder.
- **M&A forensics** (each material deal): **(1) Moat** — did it protect/widen the profit pool or an unrelated bolt-on for size? **(2) Accretion** — did per-share EPS **and BVPS** rise (earnings % > share-count %)? Quantify the change to an existing owner's per-share earnings/value, not absolute size. **(3) Financing discipline** — was an equity raise actually necessary, or dilution while sitting on deployable cash/cheap debt (a demerit)? **(4) Whose decision** — mgmt-initiated vs state/regulator-directed (per-share judged the same; mgmt-quality inference differs). **Credit non-dilutive monetisation:** subsidiary IPO/stake sale as pure OFS brings cash without issuing parent shares — quantify vs carrying cost; **always distinguish a promoter OFS (non-dilutive to you) from a fresh issue (dilutive).**
- **Leadership & execution:** **guidance-vs-delivery table** (≥4 points); separate categories — mgmt may be reliable on volume/asset-quality but chronically over-optimistic on price/margin; **misses clustering on a variable mgmt doesn't control = evidence for §1's moat conclusion**, not just a forecasting demerit.
- **Corporate alignment:** promoter/insider %, **pledged** shares, board/exec shake-ups, 8yr+ holding stability — read through the taxonomy, not generically.

## §3 Forensic cash flow & operational risk *(HARD GATE)*
- **Accounting profit vs cash:** PAT vs CFO; cash-conversion cycle (debtor+inventory vs payable days) over 3yr; cash trapped in "unbilled revenue"/"retention money"? **Cumulative CFO/PAT over 5–7yr is more diagnostic than any single year.** State explicitly whether it's a **working-capital value trap**; distinguish a genuine commissioning trough (CWIP-driven, inventory-led) from a structural trap (debtor-led). Lenders/insurers → substitute asset-quality gate; report **NNPA%networth** (tells you if book needs a haircut) + PCR + CET1.
- **Earnings-quality direction (required):** did 3yr profit growth come from **operating expansion** (volume×price×mix, margins up) or a **declining cost/provision line** (falling credit/raw-material costs, write-backs, depressed base, other income)? A ramp driven by a cost line now at a **cycle floor** is a spent tailwind that will reverse — name which. **Op-profit falling while PAT rises = clearest signal the tailwind is exhausted.**
- **Top structural risks + imperfect→perfect path:** top 3–4 existential risks (client concentration, regulation, debt, raw-material margin). Is it an "imperfect" business with a visible fix over 24–36mo? **The fix must be AHEAD of you** — if the clean-up already happened (asset quality repaired, margins normalised, multiple re-rated off the distressed base), you're arriving *after* the repair (the opposite of the setup). Quantify each risk as an EPS/BVPS sensitivity. **Pull live legal/regulatory/lease/licence items from §0.3 with dates;** for a single-asset/lease/licence business a live threat to tenure/licence is existential and can independently cap the verdict. Binary out-of-mgmt-hands outcomes (court ruling, lease non-renewal, licence cancellation) → explicit **bear scenario with probability + ₹ impact**, not a footnote.

## §4 Valuation — reverse & forward DCF *(LENS)*
Baseline: in hyper-growth **don't use standard FCF** (growth capex over-penalises) — use **Owners' Earnings** (NI + D&A − *maintenance* capex) or normalised OCF before growth capex. Financials → §0.2 substitutes (residual income, justified P/B), and say so.
**Discount-rate policy:** constant base **10–12%** (a stable yardstick, not re-derived from the risk-free rate). **15% only for genuinely higher-risk businesses on their own merits** — weak/narrowing moat, high cyclicality, heavy customer/geography concentration, unproven execution, opaque model, **extreme leverage, controlling shareholder with a dilution record** — **not** a reflex for micro-cap/SME. Show **10/12/15% side by side**, then recommend the single rate fitting THIS business and justify from its risk profile. Intermediate (13–14%) allowed if justified from named characteristics (list what argues higher and lower) — still show the three.
- **Reverse DCF (primary):** back out the 10yr implied CAGR at each rate (financials: **implied sustainable ROE**). Compare to what's **realistically achievable, quantified from TAM×plausible share** + secular tailwinds (financials: guided RoA×leverage, mgmt/consensus ROE). **Cap the achievable number at the §1 capacity ceiling (mandatory):** achievable = the **company's** capacity-limited rate, not the industry's — while capacity-constrained, achievable volume growth is **price/mix only** until dated new capacity; model new capacity as a **step + ramp from its commissioning date**, not a smooth decade rate. *(This is the specific error that turned a prior IMCL run into a false Buy: 13% "base case" = industry demand growth on a hospital that couldn't add beds until FY28.)* Implied **modest & clearly beatable** → gap = margin of safety + re-rating fuel → lean **Buy**; implied **≥ achievable** → re-rating largely spent → **Wait/Watch**.
  - **Asymmetry:** reverse DCF is reliable at *pulling you back from euphoria*, unreliable at the *false reject* — a **high** implied number on a genuine hypergrowth machine in a huge durable market is often *achievable*; don't auto-reject. It may push to Watch; it may not kill an A+ business alone.
  - **Asymmetry-applicability test:** the false-reject warning protects businesses with **expanding returns + undiscovered runway**; it does **not** protect one with contracting margins, flat/negative per-share, and a fully-discovered register. State which case you're in, or the clause becomes a universal excuse.
- **Forward DCF (sanity only):** Bear/Base/Bull over a 10yr high-growth phase into ~5% terminal, grounded in industry dynamics/competition/execution history; compute across **all three rates → an IV RANGE, never a point**; flag terminal sensitivity. **Model-fragility disclosure:** where output explodes as g→discount rate (endemic to residual-income/DDM on financials), show a small sensitivity grid and **name the most robust anchor** (usually a justified-multiple table + peer cross-check); don't present a fragile point estimate as the finding.
- **Double-counting flag (required):** a higher rate mechanically raises the implied growth the price "requires," so applying 15% **and** penalising "implied growth too high" charges risk twice. Whenever you use >10–12%, state whether the verdict double-counts and re-check at 10–12%; say which rate you stand behind. **State whether the verdict is stable across the rate range or flips** — a call that holds at only one rate is about the rate, not the business.

## §5 Re-rating, operating-leverage inflection & catalyst
- **Valuation trap:** if it hits its growth but the multiple de-rates, map the ₹ downside (e.g. a 25% grower de-rating 60x→20x). Identify which dominates: **multiple contraction** (high-multiple growth) or **earnings contraction** (low-multiple cyclical — multiple can barely fall further but the earnings base can halve). Different monitoring, different triggers.
- **Optical illusion — show a table:** price; TTM EPS & P/E; FY+1/FY+2 EPS (state drivers — capacity commissioning/capex→opex, normalising base, order-book conversion, operating leverage); implied forward P/E. Read it off (e.g. *"₹500 ÷ ₹10 TTM EPS = 50x; EPS to ₹18 (FY+1) then ₹28 (FY+2) → fwd P/E ~28x then ~18x — de-rates through earnings even if price is flat"*). **Distinguish non-linear from linear compression:** 50→28→18x = stored leverage; 6.0→5.5→5.1x off a single-digit base = ordinary growth, signals nothing. **Reverse check — name the cycle-extreme input:** cheap on TTM but on **peak/cyclical EPS** about to mean-revert (so forward P/E is *higher* — a trap)? Identify the extreme input (credit cost, commodity spread, freight, realisation, utilisation, write-back), **re-run the multiple from the current extreme to mid-cycle** on both P/E and justified multiple. A low multiple on unsustainable earnings is not a discount.
- **Operating-leverage inflection ("profits about to explode" — the RJ setup):** fixed cost base already built & paid; revenue just crossing/about to cross breakeven so **each incremental rupee falls almost entirely to EBIT** (non-linear margin/profit expansion); depressed current margins keep the crowd away — which is why it's cheap. Diagnose with numbers:
  1. **Contribution margin** = (revenue − variable cost)/revenue; high-fixed + high-contribution = most explosive.
  2. **Breakeven position:** sweet spot = revenue at/just past breakeven. **If already at/above historical PEAK profitability, the setup is ABSENT — say so and stop.** (Looks for depressed-and-about-to-inflect, not strong-and-about-to-normalise.)
  3. **Why margins AND returns are depressed (temporary vs structural):** **temporary/self-correcting** — a just-commissioned plant inflates the capital-employed denominator while depreciation/interest/fixed-opex drag the numerator and revenue hasn't ramped, so ROCE/ROE/ROIC **trough right after commissioning then recover** (often above the old level) as utilisation climbs (under-absorption margins behave identically); **structural (reject)** — returns eroding despite full utilisation, competition compressing pricing, or no capex explanation. **Demand evidence:** name the plant, commissioning date, utilisation ramp, and order-book that fills it — "just temporary" with no named driver is how value traps get rationalised. Separate the mechanical (denominator grew) from the earned (returns recovering). Check the metric isn't at a decade *high*.
  4. **Utilisation runway:** low utilisation on a built-out base = long leverage runway, little incremental capex. **Check the funding side:** if the input constraint (deposits, working capital, raw-material) grows slower than output, that's a constraint forming, not headroom.
  5. **Quantify the non-linearity:** apply contribution margin to expected 2–3yr incremental revenue at flat fixed costs; show the disproportionate EBIT/PAT jump (e.g. *"~55% contribution margin, fixed costs flat: +30% revenue lifts EBIT ~2x, EBIT margin 8%→14%"*). **Validate it's operating** — strip other income, one-offs, write-backs, low-base flattery (cross-ref §3).
  6. **Trigger + guardrails:** name the top-line driver (order book, demand, plant ramp, distribution); confirm fixed costs are genuinely fixed and **ROE/ROCE rise as revenue scales — leverage needing proportional fresh capital is not true operating leverage.**
- **Catalyst, credibility & dead-money risk:** cheapness doesn't re-rate — a **catalyst** does; a good cheap business can languish for years without one. **Spent-Catalyst Inventory (required table)** — mark each SPENT/LIVE/SPECULATIVE with evidence:

  | Catalyst | Status | Evidence |
  |---|---|---|
  | Margin/asset-quality normalisation | | |
  | Multiple re-rating off a distressed base | | |
  | Capacity commissioning / order-book conversion | | |
  | Value unlock (demerger, subsidiary listing, stake sale) | | |
  | Index inclusion | | |
  | Institutional entry / sell-side initiation | | |
  | Debt payoff / deleveraging | | |

  **A name whose catalysts are predominantly SPENT is structurally different from one with LIVE catalysts at the same valuation — the verdict must reflect this.** Then name the **specific, credible, time-bound (~1–3yr) catalyst** forcing discovery; assess credibility, nearness, and whether it's **within management's control or exogenous** (rate cycle, commodity, policy) — an exogenous catalyst with no timeline is a **hope**, not a catalyst. No credible catalyst → **prolonged dead money even if the thesis is right**; haircut conviction/IRR because **time is a cost** (3x/8yr ≈ 15% IRR; 3x/3yr ≈ 44%). Distinguish "no catalyst yet → Watch" from "catalyst imminent → Buy." **Two dead-money causes — name which:** (a) **obscurity** — real mispricing that eventually closes (wait); (b) **correct pricing** — fully discovered, fairly valued, only fundamentals move it (leave). Identical on a chart, opposite conclusions.

## §6 Multibagger traits scanner (score explicitly)
- **Lynch:** dull/boring/ignored industry? Low institutional ownership? Insider buying/sensible buybacks? Inventory growing slower than sales? Hidden-asset play (quantify as %mcap; <~10% = real but not thesis-changing).
- **Kedia SMILE:** **S** — small enough for non-linear expansion; identify the institutional threshold (~₹5–6kcr) and **confirm free float/daily traded value are deep enough for funds to enter** (a stock no institution can buy can't re-rate); **liquidity that's adequate *because institutions are already in* = fail**; report the **multiple of threshold** (1.2x = graduation-zone judgement; 20x = category error). **M** — battle-tested through ≥1 full down-cycle without complacency. **L** — aggressive credible scaling + execution velocity; **guidance being *lowered* = evidence against aspiration.** **E** — small fish/massive expanding pond; can TAM/SAM absorb a 10x revenue scale-up over a decade? **Test the fish too** — a vast TAM is irrelevant if the company's own guided growth compounds to only 2–3x; do the arithmetic.
- **Buffett/Munger:** undeniable pricing power? Sustained ROE/ROCE >20% **without heavy leverage — always report the leverage multiple** (a mediocre RoA levered up gives a flattering ROE that fails this test)? Economic engine from high-quality owner earnings, not accounting adjustments or a falling cost line?
- **Score explicitly** (e.g. "SMILE 1/4; Buffett/Munger 0/3") — a narrative summary lets weak names slide.
- **Micro→mid migration roadmap:** quantify the realistic path (revenue run-rate, order-book execution, utilisation milestones); what could permanently halt it (governance/professionalisation/main-board move/working-capital)? **If already mid/large cap, roadmap N/A → substitute: what closes the multiple gap to the best-in-class peer, and the probability?**

## §7 Napkin math
Can the thesis fit a napkin (*"earnings ~3x in 5yr, multiple re-rates 15x→25x ⇒ ~5x"*) or does it need a 10-tab model where dozens of variables must all go right? Present a **Bear/Base/Bull 5-yr total-return table:** columns = driver, exit multiple, price, multiple-of-money, price CAGR, **total return incl. dividend yield.** State the **plausible return ceiling** in one sentence (feeds §0.1 & §8). **Simplicity trap both ways:** a 10-tab model is a warning, but a *simple* thesis isn't automatically *good* — a two-variable thesis can be an honest bond substitute; say which you found. **10-year-old test:** explain what it does, why it grows, why it's cheap, in a few plain sentences; if you can't, that's a warning. **If the plain-language version reads as the bear case, say so — that is the finding.**

## §8 Ultimate verdict & allocation matrix
**Step 0 — Carry the §0.1 mandate verdict** (pass/fail + breach magnitude); a separate axis, uncurable by valuation.
**Step 1 — Hard gates first.** Either gate failed (structural decline, broken demand, governance/accounting red flags, WC-trap) → **EXIT/AVOID**, whatever the DCF says. Kill criteria come from §1–3, 5–6, not a DCF band. **Distinguish:** **"not a viable business"** (confirmed structural decline, obsolescence, permanent moat loss, fraud, WC-trap, ongoing serial dilution) → **AVOID/EXIT**, price-independent; **"not a compounder"** (viable, capitalised, honest, but flat/negative per-share, capped return, no non-linear path) → **NOT an Avoid** → RETIRE or HOLD. Name which — conflating them is the commonest error.
**Step 2 — Select the single rate** you stand behind (10–12% default; 15% only if genuinely earned; intermediate if justified). State whether the verdict is stable across the range or flips; if >base band, confirm double-count and re-check at 10–12%.
**Step 3 — Use the Base-case IV RANGE (at that rate) for price discipline** (these zones govern price/size for a business that already passed both gates):
- **BUY/Accumulate** — price at a clear discount to base IV (~30% MoS) **and** both gates pass **and** mandate passes. *GARP override:* if it clears §6 traits + "imperfect turnaround" with intact demand, an elevated **trailing** multiple doesn't block a Buy — provided reverse-DCF implied growth is comfortably **below** achievable.
- **WAIT/WATCH** — gates + mandate pass but implied ≈ achievable (thin re-rating cushion); wait for price or an earnings-driven base reset. *(Where a DCF-"expensive" great business lands — Watch, not Exit.)*
- **HOLD** — tracking fair value; no MoS to add, no reason to sell if held lower. **Only valid where the mandate screen PASSES** (else it's a deferral, not a decision).
- **RETIRE (mandate exit)** — gates pass (viable), price fair, **but mandate fails** (far outside band / discovery spent / §7 ceiling incompatible). No thesis break, no urgency; exit on capital reallocation only (Reason 1), gated on an identified replacement. Conviction N/A. Exists so a mandate decision isn't silently converted into indefinite Hold.
- **OWN — Quality-Compounder/Deep-Value (satellite)** — the constructive counterpart to RETIRE; a name failing the core mandate on growth-ceiling/size/spent-discovery but a genuine A-grade business on sale. **Size-agnostic on the upside** (home for proven mid/large-caps too big for core); **two flavours, identical gates:** (i) quality *compounder* at a discount, (ii) **proven business at a deep-value/re-rating discount** (~2–3x on wide MoS, return mostly from the discount closing + moderate growth, often a faster 2–3yr clock lifting IRR — the classic Graham/Buffett value play, **not skipped for not being a Kedia compounder**). **ALL must hold:** (1) both gates pass cleanly; (2) real per-share compounding (positive BVPS/EPS CAGR, not flat/dilution-driven — a cash cow that doesn't compound per share is a bond substitute → Hold/Retire); (3) the *only* reason it fails core is return-ceiling/size/spent-discovery, **not** quality/governance/catalyst-integrity; (4) **genuine MoS** — price ≥~25–30% below base IV, or reverse-implied growth comfortably below capacity-realistic achievable (**fair value fails this — the OWN vs Hold/Retire line**); (5) §7 base-case total return (incl. dividend) ≥~13–15% **with a survivable bear** (de-rating/dead-money, not impairment/thesis break); (6) **beats the lazy alternative** (why own this over a cheap large-cap compounder or index). **Value-trap guard:** the discount must be a *misprice* (out-of-favour/under-followed/mid-fix with the fix ahead), **not a symptom** of a breaking gate (eroding moat, deteriorating cash conversion, governance drift, spent tailwind) → that's AVOID; cheapness is necessary, never sufficient, condition 1 is non-negotiable. Sizing: satellite, no GARP conviction score — a one-line suitability note. **Available only if a satellite sleeve is run; else collapses to RETIRE/pass.**
- **TRIM** — price bakes in Bull-case perfection; multiple-contraction risk rising. Trim 20–30%.
- **EXIT/SELL** — either a "not-viable" hard-gate failure **or** *extreme, unachievable* euphoria (priced far beyond any plausible growth even at your rate). Ordinary DCF-overvaluation is Trim/Wait, not Exit.

**Step 4 — VERDICT COHERENCE CHECK (mandatory):**

| Check | If yes → permitted |
|---|---|
| Either hard gate failed as "not viable"? | **EXIT/AVOID only** |
| Business quality failed as "not a compounder" only? | **RETIRE or HOLD** — never Buy |
| Mandate screen failed on quality/governance? | **AVOID/EXIT** — satellite closed |
| Mandate failed ONLY on growth-ceiling/size, gates clean, per-share compounding real? | **Retire/Hold at fair value; OWN only at a genuine discount** — never core Buy |
| Calling OWN at fair value (no MoS)? | **Incoherent** — downgrade to Hold/Retire |
| Portfolio-fit NO for the *core* sleeve? | Only if paired with RETIRE / OWN-satellite / TRIM / EXIT — "core fit NO / action core-Buy or Hold" is incoherent |
| Catalysts predominantly SPENT? | Buy requires explicit justification of what re-rates it from here |
| Verdict flips with the discount rate? | Disclose; don't present a rate-dependent call as a business conclusion |
| Recommendation influenced by holder's avg cost / unrealised P&L? | **Strike it** — re-derive as if opening today at the current price |

**If any row is violated, fix the verdict, not the analysis.**

**THE FINAL VERDICT** (brutal executive summary at the current price): (1) **Tactical action** — Buy&Accumulate(core)/Own—Quality-Compounder(satellite)/Wait&Watch/Hold/Retire/Trim/Exit — unequivocally; (2) **the single rate you stand behind**, why, whether it double-counts, whether stable across 10–15%; (3) **IV/target RANGE** (never a point), implied upside/downside, MoS required to buy; (4) **re-rating catalyst & discovery runway** — or explicit statement the runway has been run; (5) **Portfolio fit YES/NO** — deserves a place in a concentrated small-capital multibagger book (weigh multibagger probability vs §3/§5 existential risks)? If NO for core, state whether it qualifies for **your satellite sleeve** (gates clean + per-share compounding + discount → OWN) else name the external sleeve it suits (income, large-cap value, bond substitute); (6) **Conviction 0–10 — Buy calls only** (else N/A; optionally give a counterfactual "had this been a Buy it'd cap at X because…").

### Conviction rubric (0–10)
Measures **confidence the thesis plays out** (probability × evidence), **NOT return size** — a near-certain 2.5x outranks a low-probability 10x; concentrate capital in highest-*conviction* names, sized by conviction. **Gated by the weakest hard-gate pillar, not an average** — a strong business with a governance stain isn't a 7 because the average says so. Pillars: business quality/moat; governance/forensics; cash-backed earnings/no WC-trap (financials: asset quality); per-share compounding record; MoS & reverse-DCF headroom (how far implied sits below achievable); catalyst clarity/nearness (and how much is SPENT); residual/existential risk. **Bands (don't cluster at 7–8):** 9–10 exceptional/rare (all gates pristine, wide MoS, near-certain trajectory, clear near-term catalyst, minimal residual — a handful in a career); 7–8 strong (gates clean, good MoS, credible catalyst, 1–2 manageable risks); 5–6 speculative/starter (hinges on 1–2 things going right — small position); 3–4 weak (should be Watch/Retire — re-examine); 0–2 inconsistent with a Buy. **Required with the score:** (a) **rationale** — 2–3 sentences pillar-by-pillar so the number is reconstructable (not "8/10, strong buy"); (b) the single biggest **capping factor** (weakest link); (c) the **observable that would raise conviction ≥2** (e.g. two more quarters of margin delivery, a marquee order converting, a board upgrade); (d) **coherence** — a >10–12% rate for genuine risk is usually inconsistent with 9–10; (e) **sizing** (8+ largest; 5–6 starter; <5 unfunded).

### Entry & accumulation plan (Buy only) — all figures are templates the investor calibrates
- **Target size anchored to conviction:** 9–10 top-tier/full; 7–8 core; 5–6 starter (earn the right to size up); <5 unfunded. Respect the single-name **max cap**; the target is a destination reached over time, not one click.
- **Tranche by reason, not calendar:** T1 on thesis intact + price in-band; add-ons on (a) deeper MoS without thesis impairment, (b) a thesis-confirming event (delivery quarter, catalyst, capacity commissioned, order-book conversion), (c) thesis-neutral drawdowns. **Average down only while gates hold** — a gate break is an Exit, not a discount to add into.
- **Accumulation price bands in ₹** (off the IV range): aggressive-accumulate <~70% of base IV (larger tranches); accumulate within the MoS zone (standard); pause as price nears fair value and the reverse-DCF cushion thins (the Watch line). State actual bands ("accumulate ₹X–Y; add aggressively below ₹X; stop above ₹Z").
- **Averaging up on confirmed strength** (feed your winners) is legitimate and distinct from averaging down — still respects the max cap and a sensible price vs the *updated* IV.
- **Exit is thesis-based, not a price stop** — micro-caps are too volatile for a mechanical stop; the real stop is a hard-gate failure (§1–3, 5–6). Name the observable full-Exit events.
- **For RETIRE, issue no accumulation plan** — state reference bands (incl. the level at which it becomes a genuine value proposition for a different mandate) and move to sequencing.

### Satellite sizing & discipline (OWN only)
- **Sleeve cap first, name second:** a bounded slice set in advance (template ~10–25% of capital; the rest is core GARP). No name funded if it pushes the sleeve over cap. The satellite is ballast/opportunistic value, not the main event.
- **Per-name ~2–5%,** sized by quality + discount + downside-boundedness, **not upside** — it should almost never be your largest position (a 5–6 core starter can outrank it; an 8+ core compounder always does).
- **The discount is the trigger — its disappearance is the exit:** when price re-rates into fair value (cushion ~nil), the thesis is complete — stop adding, consider trimming/RETIRE back toward core. Held past fair value it's a low-return Hold occupying mandate capital.
- **Tranche on discount depth, not catalyst:** standard within the discount band, larger if it de-rates further with gates intact, stop at fair value. No catalyst is acceptable here (unlike core) *provided* downside is bounded and you're paid to wait (dividend/buyback).
- **Same hard-gate Exit** as everything else (governance, cash-flow/asset-quality, structural demand, a §0.3 live-events shock) — the discount doesn't protect a broken thesis; no averaging down into a thesis break.
- **Annual "still earns its seat" review:** re-clear the OWN gate at the current price (zero-shares test); if no discount, no per-share compounding, or a 7+ core Buy needs funding, it RETIREs. A waiting room with rent control, not a retirement home.
- **One-line suitability note (in place of conviction):** quality grade, discount size, base-case total return + downside floor, why it beats the index. Compounder e.g. *"A-grade, ~30% below base IV, ~15% total return, survivable ~−15% bear, owned over the index for the discount + a live margin-normalisation trigger the index lacks."* Deep-value — name the **re-rating trigger + timeframe** e.g. *"proven B+ franchise, ~40% below base IV, ~2.5x over ~3yr as the cyclical trough normalises and the discount narrows, bear ~−20% survivable."* Deep-value with bounded downside + near-term trigger sits at the top of the per-name band; a slow compounder with no trigger at the bottom.

### Exit & sell discipline (the hardest decision)
**Default = do nothing.** The costliest error is selling a compounder too early — people sell at 2–3x and forfeit the 20–100x. **Burden of proof is on the sell** ("buy right, sit tight"); a rising price is not a reason. Re-underwrite each period but require a named reason below.
**Only valid reasons to sell:**
1. **Materially better opportunity (reallocation)** — capital demonstrably better deployed on a **risk-adjusted** basis; high bar (reinvestment, re-entry-timing, tax-drag risk); "also attractive" is insufficient. **1a — return upgrade:** requires a **named, analysed, higher-conviction candidate.** **1b — mandate exit (RETIRE):** sound & fairly priced but return ceiling incompatible with the mandate; cleared in principle by §0.1, awaits a replacement. **Cash test:** *vs an identified in-mandate 7+ conviction Buy* → reallocate; *vs cash while you search* → **do not sell** ("something better probably exists" isn't a destination). **Tax:** the drag caution assumes a *gain* — at a **loss** there's no drag (may offset other gains); don't import it into a losing position.
2. **Egregious valuation AND a peaking earnings engine — both must co-exist.** Neither alone is a full Exit: a rich multiple while EPS still compounds is a **Hold** (grow into it; if euphoric, **Trim**); a peak the market *already* recognised is too late (multiple already collapsed). The signal lives in the **narrow window where the multiple is still euphorically high while earnings are quietly topping** — your edge is acting inside that lag. Catch it **(a) fundamentals-led** (read the peak early: order book thinning, capacity fully used with no expansion, margins at a structural ceiling, TAM saturating, a cost/provision line at a cycle floor — while the multiple is rich) or **(b) market-led** (the multiple **rolls over despite still-growing earnings** — the stock stops rising on good results; investigate but confirm against fundamentals, not sentiment noise). Waiting for both a visible peak *and* a full re-rate = selling at the round-trip bottom.
3. **Fundamentals change (thesis break)** — moat erosion, governance/forensic red flags, structural demand decline, emerging WC-trap, serial dilution, capital-allocation deterioration (the hard-gate failures). **Non-negotiable, price-independent full Exit**, up 10x or down 50%.
4. **Reverse DCF structurally impossible (GARP-specific)** — price implies a growth rate unachievable under any realistic scenario because the **TAM itself can't support it** (a genuine ceiling, not merely a high number). Respect the §4 asymmetry: high-but-*achievable* is still a Hold.

**Trim vs full Exit:** **Trim** for position-size/risk or reason 2's extreme valuation while earnings still grow; **full Exit** for reason 3 always, reason 2 when valuation is egregious AND earnings peaking, reason 4, or reason 1.
**NOT reasons to sell:** an arbitrary round-number target; "it's already 2x/3x"; volatility/drawdown with the thesis intact; macro noise; boredom/impatience; a high P/E *while earnings still compound*.
**Cost-basis anchoring — reject in BOTH directions:** *"already 2x, lock it in"* and *"down 10%, wait for break-even"* are the same error (the market doesn't know your entry). Exit on merits whether up or down; hold on merits at any cost basis.
**Operational test:** re-derive as if you held **zero shares** and were deciding to open today at the current price. If "no, wouldn't buy here and it doesn't fit the mandate," holding is a decision you wouldn't make fresh — "I'm underwater" is an anchor, not an argument. (This also cuts against panic-selling: if you *would* open it today, a paper loss is irrelevant — hold.)
**Business-specific pre-committed triggers (required output), grouped by reason 1–4, observable/monitorable, decided now:** e.g. loss/renegotiation of a named anchor client; gross/EBITDA margin < X% for two consecutive quarters (moat erosion); **promoter pledging appears** or stake < Y%; **any fresh equity issuance below Z× book** (distinguish from a non-dilutive promoter OFS); auditor qualification/resignation; CFO/PAT divergence opening or receivable days breaking out; a named competitor's capacity compressing pricing; TAM saturation (share > Z%, pond not growing); P/E egregious *while* growth decelerates below a stated threshold. **For RETIRE, include the Reason-1b trigger: "an identified in-mandate candidate at 7+ conviction requiring funding."** Each specific enough to recognise in a quarterly result.
**Exit sequencing (RETIRE & Reason-1):** **find the replacement first, then fund it from this position** — prevents both selling-into-cash-and-drifting and holding-forever-because-no-forcing-event. Note whether position size creates urgency (a small position needn't be touched first).
